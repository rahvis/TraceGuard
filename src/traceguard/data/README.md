# Packaged research data

- `synthetic-medical-v2.json` is the packaged corpus (`CorpusCatalog.load_default`).
  It is entirely fictional, authored for this artifact, and dedicated to the
  public domain under CC0 1.0 Universal:
  <https://creativecommons.org/publicdomain/zero/1.0/>. It grades sensitivity
  into four rungs (L0 routine, L1 guarded, L2 elevated, L3 sensitive), giving
  6 topics x 4 levels x 2 membership arms = 48 cases. Character counts are
  matched across the four rungs of every topic; `scripts/gen_pa_corpus.py`
  fails the build otherwise, because text volume rising with the level would be
  a confound perfectly correlated with the ordinal axis.
- `synthetic-medical-v1.json` is the previous, binary (routine/sensitive) corpus
  and expands to 24 cases. Same license. **It must not be edited.** `dataset_hash`
  is taken over the canonical JSON of the whole file and is embedded in every
  signed receipt, so the archived journals in `artifacts/` verify only against
  these exact bytes. It still loads: the loader falls back to this file's
  implicit `["routine", "sensitive"]` framing pair, and resolves "sensitive" to
  the *top* rung, so its seven-hop depth and repair/revision fixture flags keep
  their original meaning.
- `paper-reported-unverified.json` transcribes values from the supplied paper and
  is distributed with the paper/source under the repository license. It is not
  experimental evidence generated by this code.

The two files must never be merged into one result namespace. Current-run
analysis reads synthetic cases and writes new metrics; it does not import paper
reference values.
