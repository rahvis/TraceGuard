04 · Reproduce

Run the artifact from a clean checkout

The fixture path requires no external model. Azure OpenAI runs read a key only from the server environment; never paste one into this console.

DockerStart the console
cp .env.example .env
docker compose up --build
# open http://localhost:8000
CLIRun a deterministic fixture
docker compose run --rm traceguard \
  traceguard run --provider fixture \
  --condition full_pad --case-id med-syn-001 --seed 7

Pinning, dataset hashes, generated artifacts, analysis commands, and limitations are documented in the repository README. A fixture run validates reproducibility of the software path only.
